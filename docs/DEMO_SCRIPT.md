# Judge Demo Script

## 0:00-0:10: The hook

"Passwords prove what you know once. DBLA asks a quieter question: does this still look like the person who signed in?" Open the app on the calibration screen.

## 0:10-0:22: Build a behavioral baseline

Type naturally and move the pointer through the field. Explain that DBLA measures rhythm, not words. Point out that progress is based on signal count, not captured text. Enter live mode.

## 0:22-0:35: Normal session

Call out the 94-ish trust score, green heartbeat, and drift history. Move, scroll, and type while the browser streams a vector every 1.5 seconds. Show the anonymized team metrics below.

## 0:35-0:47: Takeover simulation

Invite a judge to type quickly with a different rhythm, or inject repeated timing values from the console. The gauge should move down. Point to the explanation copy: it identifies the largest z-score deviations in plain English. Mention the bot probability when the cadence is unnaturally uniform.

## 0:47-0:55: Response ladder

The medium state is a passive checkpoint, not a disruptive CAPTCHA. Use the rapid corner-to-corner pointer gesture to demonstrate the hidden panic gesture: the app holds the session immediately.

## 0:55-1:00: Close with the moat

"Every signal you saw was derived in the browser. No keystroke content, text, or raw pointer trail left the device. The result is continuous, adaptive, explainable authentication that can follow the user across devices."
